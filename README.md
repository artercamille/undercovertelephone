# Les jeux Aura (téléphone)

Cinq jeux de soirée avec **un seul téléphone** qui tourne autour de la table.

- **Aura Cover** (Undercover) : https://artercamille.github.io/undercovertelephone/
- **Aura Spy** (trouvez l'espion) : https://artercamille.github.io/undercovertelephone/spy/
- **Aura Time** (décris, un mot, mime, en équipes) : https://artercamille.github.io/undercovertelephone/time/
- **Aura Tête** (le téléphone sur le front) : https://artercamille.github.io/undercovertelephone/tete/
- **Aura Loup** (Loup-Garou, le téléphone fait le narrateur) : https://artercamille.github.io/undercovertelephone/loup/

## Les installer comme des applis

- **iPhone** : ouvre le lien dans **Safari** → bouton Partager → **Sur l'écran d'accueil**.
- **Android** : ouvre le lien dans **Chrome** → menu ⋮ → **Installer l'application** (ou « Ajouter à l'écran d'accueil »).

Chaque jeu a sa propre icône, s'ouvre en plein écran et marche même sans connexion.
Les prénoms et les stats restent enregistrés dans le téléphone (les prénoms sont partagés entre les jeux).
