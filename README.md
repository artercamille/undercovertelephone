# Aura · Jeux de soirée

Six jeux de soirée dans une seule appli, avec **un seul téléphone** qui tourne autour de la table.

**Ouvrir l'appli : https://artercamille.github.io/undercovertelephone/**

| Jeu | Le principe | Joueurs |
| --- | --- | --- |
| **Aura Cover** | Undercover : trouve qui n'a pas le même mot que toi | 3 à 12 |
| **Aura Spy** | Tout le monde connaît le lieu, sauf l'espion | 3 à 12 |
| **Aura Time** | Décris, un seul mot, puis mime, en équipes | 4 et plus |
| **Aura Tête** | Le téléphone sur le front, les autres te font deviner | 2 et plus |
| **Aura Loup** | Loup-Garou, le téléphone fait le narrateur (22 rôles) | 5 à 18 |
| **Aura Apéro** | Défis, votes, « je n'ai jamais », règles et virus | 2 et plus |

## L'installer comme une appli

- **iPhone** : ouvre le lien dans **Safari** → bouton Partager → **Sur l'écran d'accueil**.
- **Android** : ouvre le lien dans **Chrome** → menu ⋮ → **Installer l'application**.

Une seule icône « Aura » apparaît sur l'écran d'accueil : on la lance, on choisit le jeu dans le menu. L'appli s'ouvre en plein écran et marche même sans connexion.
Les prénoms sont partagés entre les jeux et chaque jeu garde ses stats, dans le téléphone.
