# Aura Cover (téléphone)

Undercover avec **un seul téléphone** qui tourne autour de la table.

**Jouer : https://artercamille.github.io/undercovertelephone/**

## L'installer comme une appli

- **iPhone** : ouvre le lien dans **Safari** → bouton Partager → **Sur l'écran d'accueil**.
- **Android** : ouvre le lien dans **Chrome** → menu ⋮ → **Installer l'application** (ou « Ajouter à l'écran d'accueil »).

L'icône apparaît sur l'écran d'accueil, le jeu s'ouvre en plein écran et marche même sans connexion.
Les prénoms et les stats restent enregistrés dans le téléphone.
