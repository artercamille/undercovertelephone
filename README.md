# Tablée · Jeux de soirée

Des jeux de soirée dans une seule appli, avec **un seul téléphone** pour toute la table.

**Ouvrir l'appli : https://artercamille.github.io/undercovertelephone/**

| Jeu | Le principe | Joueurs |
| --- | --- | --- |
| **L'Intrus** | Trouve qui n'a pas le même mot que toi | 3 à 12 |
| **L'Espion** | Tout le monde connaît le lieu, sauf l'espion | 3 à 12 |
| **Juste Milieu** | Un indice, un cadran : trouvez où il pense | 4 et plus |
| **Nom de Code** | Un mot pour faire deviner plusieurs cartes | 4 et plus |
| **Tu Préfères** | Deux choix impossibles, tout le monde vote | 2 et plus |
| **Le Faux Artiste** | Tout le monde dessine, un seul fait semblant | 3 à 10 |
| **Le Dernier Mot** | Trouvez le mot secret, puis le complice | 4 à 10 |
| **Trois Manches** | Décris, un seul mot, puis mime, en équipes | 4 et plus |
| **Sur le Front** | Le téléphone sur le front, les autres font deviner | 2 et plus |
| **Les Loups** | Le Loup-Garou, avec le téléphone comme narrateur | 5 à 18 |
| **L'Apéro** | Défis, votes et « je n'ai jamais » | 2 et plus |

## L'installer comme une appli

- **iPhone** : ouvre le lien dans **Safari** → bouton Partager → **Sur l'écran d'accueil**.
- **Android** : ouvre le lien dans **Chrome** → menu ⋮ → **Installer l'application**.

L'appli s'ouvre en plein écran et marche même sans connexion. Les prénoms sont partagés entre les jeux et restent dans le téléphone.
